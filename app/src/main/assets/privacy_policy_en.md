## 1. Core principles

## 2. Information processing of this application ontology

### 2.1 Information we do not collect

This application body** will not** collect any of the following information:

- Personally identifiable information (name, email, phone number, address, etc.)
- Device identifier (IMEI, MAC address, Android ID, advertising ID, etc.)
- Address book, call history, text messages
- List of installed apps
- Photos, media, files (except backup files actively imported by users)
- Any form of biometric information
- health information of any kind

### 2.2 Locally stored information

The following information is only stored locally on your device and is not uploaded to any server:

- Application settings (language, temperature units, wind units, update interval, etc.)
- Added city list
- API configuration (weather provider, API key, etc.)
- AI service configuration (API address, API key, model name, etc.)
- Notification preferences
- local backup file
- API usage statistics (only for local quota management)

### 2.3 Location information

This application only applies for ** rough location permission ** (`ACCESS_COARSE_LOCATION`), which is used to obtain meteorological data of the current city. When getting location:

- Location information is sent directly to your selected weather data provider (Open-Meteo by default) and **does not pass through any developer-operated server**;
- Location is only used for a single weather query and is not stored or tracked long-term;
- You can revoke location permissions at any time in your device's system settings.

## 4. Data security

### 4.1 Local data security

All data of this application is stored on your device, and data security depends on your device's own security measures (lock screen password, encrypted storage, etc.). It is recommended that you keep your device's operating system and this app up to date.

### 4.2 Third-party transmission security

This application communicates with third-party APIs via HTTPS encrypted protocol. However, the developer does not guarantee the data security measures on the third-party server side.

### 4.3 Backup and restore

The file generated by the app's backup feature contains all of your local settings and API configuration. These backup files are stored unencrypted on your device's external storage. Please keep the backup files properly. The developer is not responsible for any problems caused by the leakage of backup files.
