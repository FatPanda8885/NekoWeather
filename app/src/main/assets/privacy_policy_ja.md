# プライバシーポリシー

**発効日: 2026 年 7 月 18 日**

## 重要なヒント

本プライバシーポリシー（以下「本ポリシー」）は、**NekoWeather（猫猫風雨）**（以下「本アプリ」）に適用されます。**本アプリをインストール、起動、またはその他の方法で利用した時点で、本ポリシーを読み、理解し、同意したものとみなされます。**

このポリシーに同意しない場合は、直ちにこのアプリケーションの使用を中止し、アンインストールしてください。

---

## 1. 基本原則

** このアプリケーションは、個人情報を収集、保存、または開発者サーバーにアップロードすることはありません。 **

このアプリにはバックエンド サーバーがなく、データは開発者に送信されません。すべてのデータ (設定、都市リスト、バックアップ ファイルなど) はデバイスのローカルにのみ保存されます。

このアプリケーションはオープン ソース プロジェクトであり、**GNU General Public License v3.0 (GPLv3) ** に基づいてライセンスされています。誰でもこのアプリケーションの完全なソース コードを表示して、このプライバシー ポリシーに記載されているデータ処理の実践を確認できます。ソース コードは [GitHub](https://github.com/FatPanda8885/NekoWeather) でホストされています。

## 2. 本アプリケーションオントロジーの情報処理

### 2.1 当社が収集しない情報

このアプリケーション本体** は、次の情報を** 収集しません。

- 個人を特定できる情報（氏名、メールアドレス、電話番号、住所など）
- 端末識別子（IMEI、MACアドレス、Android ID、広告IDなど）
- アドレス帳、通話履歴、テキストメッセージ
- インストールされているアプリのリスト
- 写真、メディア、ファイル (ユーザーがアクティブにインポートしたバックアップ ファイルを除く)
- あらゆる形式の生体情報
- あらゆる種類の健康情報

### 2.2 ローカルに保存された情報

次の情報はデバイス上でローカルにのみ保存され、サーバーにはアップロードされません。

- アプリケーション設定（言語、温度単位、風力単位、更新間隔など）
- 都市リストを追加しました
- API 設定 (天気予報プロバイダー、API キーなど)
- AIサービスの設定（APIアドレス、APIキー、モデル名など）
- 通知設定
- ローカルバックアップファイル
- API 使用状況統計 (ローカル クォータ管理のみ)

### 2.3 位置情報

このアプリケーションは、現在の都市の気象データを取得するために使用される ** 大まかな位置許可 ** (`ACCESS_COARSE_LOCATION`) にのみ適用されます。位置情報を取得する場合:

- 位置情報は選択した気象データプロバイダー（既定では Open-Meteo）へ直接送信され、**開発者が運営するサーバーを経由しません**。
- 位置情報は 1 つの天気クエリにのみ使用され、長期間保存または追跡されません。
- 位置情報のアクセス許可は、デバイスのシステム設定でいつでも取り消すことができます。

## 3. サードパーティコンテンツプロバイダーのプライバシーとデータ収集

**重要: このアプリケーションは、サードパーティのコンテンツプロバイダーがあなたの情報を収集しないことを保証しません。 **

### 3.1 第三者が収集する可能性のある情報

アプリがサードパーティのコンテンツプロバイダーにデータを要求すると、デバイスはサードパーティのサーバーと直接通信します。これらの第三者は次の情報を収集する場合があります。

- **ネットワーク情報**: IP アドレス、リクエスト時刻、ユーザー エージェント (アプリケーションのバージョン番号を含む)
- **位置情報**: 天気予報のクエリ中に送信される経度と緯度の座標または都市名
- **デバイス情報**: HTTP リクエストに自動的に含まれるメタデータ
- **API 使用記録**: リクエスト頻度、リクエスト内容、API キーに関連付けられた使用量

## 4. データセキュリティ

### 4.1 ローカルデータのセキュリティ

このアプリケーションのすべてのデータはデバイスに保存され、データのセキュリティはデバイス自体のセキュリティ対策 (ロック画面のパスワード、暗号化されたストレージなど) に依存します。デバイスのオペレーティング システムとこのアプリを最新の状態に保つことをお勧めします。

### 4.2 サードパーティの送信セキュリティ

このアプリケーションは、HTTPS 暗号化プロトコルを介してサードパーティ API と通信します。ただし、開発者はサードパーティサーバー側のデータセキュリティ対策を保証するものではありません。

### 4.3 バックアップと復元

アプリのバックアップ機能によって生成されたファイルには、すべてのローカル設定と API 構成が含まれています。これらのバックアップ ファイルは、暗号化されずにデバイスの外部ストレージに保存されます。バックアップファイルは適切に保管してください。バックアップファイルの漏洩により生じた問題については開発者は責任を負いません。
